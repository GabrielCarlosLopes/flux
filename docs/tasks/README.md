# Tasks do pipeline

`.cursor/skills/flutter-pipeline/task-template.md`

## Índice

Ver backlog completo, dependências e ordem de execução:

**[../ROADMAP.md](../ROADMAP.md)**

## Convenção de nomes

```
F<nn>-<slug-kebab>.md
```

Exemplos:
- `F00-fundacao.md`
- `F03-one-task-mode.md`
- `F08-estou-travado.md`
